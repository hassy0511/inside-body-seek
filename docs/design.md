# からだのなか だいぼうけん ― 企画・設計メモ

子ども向け（目安：小学校低学年〜中学年）の 3D アクションゲーム。
主人公はカプセル船「ミクロごう」に乗ってちいさくなり、ともだちの体のなかに入って、
病気のもとをやっつけたり、がんばっている細胞を応援したりしながら、体のしくみを学ぶ。

制作ツール：Godot 4.7（GDScript）＋ Blender 5.2（モデルは Python スクリプトで生成）。

## 1. コンセプト

| 項目 | 内容 |
| --- | --- |
| ジャンル | 3D ホバー船アクション（カート風の操作感・敵は倒しても倒さなくてもクリアできる） |
| プレイ時間 | 1 ステージ 3〜6 分。全 9 ステージ |
| 物語 | ともだちの「はなちゃん」がかぜ＆おなかの調子がわるい。ミクロごうで口から入り、臓器を順番にたすけて、最後にくしゃみで鼻から脱出 |
| 学び | 各臓器の「どこにあるか・なにをするか」と、体の中の仲間（赤血球・白血球など）と敵（ウイルス・ばいきん）を知る |
| 方針 | **こわくない・しかられない**。やられてもチェックポイントから何度でも。「やっつける」だけでなく「あつめる」「とどける」「おうえん」「たどりつく」ミッションを混ぜる |

### 入口はどこ？
口から。「ジュースといっしょに のみこんでもらう」という自然な導入にできて、
口 → 食道 → 胃 → 小腸 → 血管 → 心臓 → 肺 → 脳 とつながる順番がそのまま学びの順番になる。
出口は鼻（くしゃみで飛び出す）。鼻を入口にするのは「鼻→肺」ルートの別シナリオとして後から追加できる。

## 2. 操作（子ども向け・ボタン 2 つ）

| 動作 | キーボード | ゲームパッド | タッチ |
| --- | --- | --- | --- |
| うごく | 矢印キー / WASD | 左スティック / 十字キー | 左の丸いスティック |
| おくすり（撃つ・おうえん・話す） | スペース / Z / Enter | A（下ボタン） | 右の大きいボタン |
| ダッシュ | Shift / X | B（右ボタン） | 右の小さいボタン |
| ポーズ | Esc | Start | ⏸ |

- カメラは自動追尾のみ（カメラ操作は不要）。
- 船は臓器の「ゆか」の上をふわふわ浮いて進む（上下の操作はいらない）。壁にはぶつかるだけ。
- おくすりは **近くの敵を自動でねらう**（扇形 60°・15 m 以内の一番近い敵）。
- 仲間（赤血球など）は **さわるだけ** で応援できる。
- げんき（ハート）3 つ。敵にぶつかると 1 つへって少し吹き飛ぶ。0 になると「ちょっときゅうけい」→ 直前のチェックポイントから再開（ゲームオーバー画面は出さない）。

## 3. ミッションの種類（ステージはこれの組み合わせ）

| 種類 | 内容 | 例 |
| --- | --- | --- |
| `defeat` | 敵を N 体やっつける | むしばきんを 3 びき |
| `collect` | アイテムを N 個あつめる | ビタミンを 6 こ |
| `deliver` | あつめたものを目標へ届ける | 栄養をじゅうもうへ |
| `cheer` | 仲間に N 回さわって応援 | 赤血球を 5 こ応援 |
| `reach` | ゴールにたどりつく（チェックポイントあり） | 食道をくだる |
| `boss` | ボスを倒す（弱点が時々ひらく。応援した白血球が手伝ってくれる） | かぜウイルス大王 |
| `sequence` | 光った順番に神経にさわる（かんたんなサイモンゲーム） | 脳のしんごう |

ミッションはすべて達成してクリア。倒す系はいつでも途中で「たどりつく」に切りかえられるよう、必須の敵の数は少なめにする。

ステージ 1〜3 が「かんたん」、4〜6 が「ふつう」、7〜9 が「むずかしい」。

### 星（やる気の仕組み）
各ステージ 3 つの星：クリア／ハートをへらさずクリア／クリア後のクイズ正解。

### ものしりカード・ずかん
- ステージ開始時に 1 枚、はじめて出会った生き物・物ごとに 1 枚、クリア時に「きょうのまとめ」1 枚。
- 見たカードはタイトルの「ずかん」からいつでも読み返せる。
- 文は ひらがな・カタカナ中心。臓器名は「い（胃）」のようにひらがな＋漢字。

## 6. 技術構成

- Godot プロジェクトは `godot/`。自動ロード：`Game`（進行・ステージ切替）、`StageDB`（ステージ定義）、`SaveData`（セーブ）、`Sfx`（音）。
- ステージは **データ駆動**：`godot/src/stages/stage_db.gd` にミッション・文章・カードを定義し、
  レベルの形（壁・ゆか・敵や仲間の置き場所）は Blender スクリプトが出力する GLB に入っている
  （Empty の名前 `MK_<種類>_<名前>` がスポーン位置になる）。
- Blender 側は `blender/` の Python。`python -m blender.build_all` で全モデル・全ステージの GLB を `godot/assets/models/` に書き出す。
  キャラクターの差し替えは、同じ名前の GLB を上書きするだけ。
- 物理：`CharacterBody3D`。下向きレイで「ゆか」までの距離を測り、一定の高さにふわふわ浮く。壁は `move_and_slide` でスライド。
- 自動テスト：`tools/run_tests.sh` が Godot をヘッドレスで起動し、全ステージを読み込んで疑似プレイしてクリアまで動くことを確認する。

## 7. 今後の拡張アイデア

- 鼻から入る「空気ルート」（鼻 → のど → 気管 → 肺）。
- 「からだのちから」図鑑に、骨・筋肉・皮ふ・腎臓・肝臓のステージを追加。
- 2 人協力（白血球役をもう 1 人が操作）。
- キャラデザを描き直したら Blender で作り直し、GLB を差し替え。
