# 3D 変換用の絵の条件（すべての 3D 化の発注に共通）

> Codex（作画担当）へ。キャラクター・小物・ステージの部品を 3D にするための絵の描き方。
> `00_共通ルール.md` と食い違う場合は、**3D 変換用の絵についてはこの文書を優先**する。
> 各発注書の「3D 変換用の絵」の表と一緒に使う。

---

## 1. なぜこの条件か

Claude は、絵の**外形（輪郭）と色見本**から、Blender のスクリプトで **丸い部品を組み合わせて** 3D を作る（球・カプセル・円すい・トーラスなど）。
このゲームのキャラクターは単純な形なので、絵の外形を測って部品の寸法を決め、色は spec の hex で平らに塗る。

したがって大切なのは、
- **同じ大きさ・同じ位置で描かれた複数の向きの絵**（寸法を測るため）
- **部品ごとに境目がはっきりした塗り**（どこで部品が分かれるかを読むため）
- **hex の色見本**（塗りはそれで決める）

---

## 2. すべての絵に共通

| 項目 | 条件 |
|------|------|
| 大きさ | 正方形 **2048×2048** |
| 背景 | **透明**（アルファ付き PNG） |
| 投影 | **遠近感をつけない正投影**。カメラは対象の中心の高さ、水平に向ける（真上は真下向き） |
| 光 | 正面からの**均一で柔らかい光**。形がわかる程度の弱い陰影はよい。落ちる影・逆光・縁の光・光沢のハイライトは描かない |
| 発光する部分 | 平らな色で塗る。光のにじみを描かない（ゲームで光らせる） |
| 輪郭線 | アートバイブルの選定案に合わせる（線なしの案なら描かない） |
| 床と影 | 描かない |
| 文字など | 文字・寸法線・矢印・ラベル・署名を画像の中に入れない（説明は spec に書く） |
| 色 | spec の hex の色で塗る。広い面は 1 色で塗り、細かい模様を描き込まない |
| 描き方 | **画像生成機能で描いた絵**にする。3D ソフトで作ったモデルを撮った画像やプログラムで描いた図形は不可 |
| 1 枚 1 方向 | **1 つの画像に 1 つの向き**だけを描く（シートに並べない。表情のシートだけ例外） |

---

## 3. そろえること（最重要）

- **すべての向きで、同じ大きさ・同じ位置**：底の行、てっぺんの行を全画像で同じにする。体の中心を画像の横の中央（1024 px の列）に置く。
- 対象を画像の高さの **85〜90%** に収め、上下に余白を残す。
- 同じ形・同じ色。向きだけを変える（1 つの 3D の人形を回して描くつもりで）。
- 納品前に全方向を並べて見比べ、食い違いを直す。

---

## 4. 向き（ファイル名は `<ID>_3d_<向き>.png`）

| 向き | 内容 | |
|------|------|--|
| `front` | 正面（顔が見える向き） | 必須 |
| `back` | 背面 | 必須 |
| `side_right` | 本人の右側から見た真横（顔は画像の右を向く） | 必須 |
| `top` | 真上 | 必須 |
| `front_right45` | 本人の右前 **ちょうど 45 度** | 必須 |
| `bottom` | 真下 | 底の形が上と違うもの（船・円盤など）は必須 |
| `side_left` | 左側から見た真横 | 左右が非対称なら必須 |

- 左右非対称の部品（片側だけのドリル、片側だけの模様など）は、spec に「本人の右／左」を必ず書く。

---

## 5. 表情（顔のあるもの）

`<ID>_faces.png`：**2×2 の並び**。左上 通常、右上 うれしい、左下 びっくり、右下 いたい（または こまった）。
4 つとも**同じ大きさ・同じ位置**で、変えるのは目・眉・口だけ。顔の部分だけを大きく描いてよい（体は要らない）。
この絵だけは、1 枚に 4 つ並べてよい。

- 主人公のパイロット、ドクター・ピコ、はなちゃんは、HUD のアイコンとして**そのまま使う**ので、`W1_01` の指定（256×256 透過・1 枚 1 表情）でも納品する。

---

## 6. 小物・部品（ステージの飾り）

| ファイル名 | 内容 | |
|-----------|------|--|
| `<ID>_3d_front.png`、`_side.png`、`_top.png` | 正面・真横・真上 | 必須 |
| `<ID>_3d_front_right45.png` | 斜め 45 度（上から少し見下ろしてよい） | 必須 |

- 小物は数が多いので、**種類ごとに 3 枚（正面・真横・真上）のシートにまとめてよい**：同じ縮尺・同じ並びで部品を並べ、番号は部品に重ならない下の余白に小さく書く（このシートだけの例外）。
- 真横・真上・正面は、**同じ大きさ**（1 px が同じ長さ）で描く。spec に全長（m、ミクロごう = 1.4 m との比）を書く。
- 動く部品（べんの ふた、ボスの弱点の ふた、プロペラ）がある物は、`<ID>_3d_parts.png`（分解図：部品を少し離して並べ、つながる位置を細い線で示す）を追加する。

## 7. ステージの表面（テクスチャ）と部品

ステージは **くだ（tube）** と **ひろば（arena）** の形を Claude がスクリプトで作り、その表面に Codex の「表面の画像」を貼り、壁や床に Codex の「部品」を並べる。

### 表面の画像
- `tex_<ステージ>_<名前>.png`：**2048×2048、上下左右の端がつながる**（並べても継ぎ目が出ない）。真正面から見た平らな面、均一な光、影なし。
- 1 ステージにつき、かべ用 1 枚、ゆか用 1 枚（同じでもよい）。
- spec に、その画像 1 枚が実際の何 m 四方に当たるかを書く（例：4 m 四方）。

### 部品（かべや ゆかに置く飾り）
- 1 ステージにつき 3〜6 種（例：口なら「は（歯）」「のどちんこ」「したの ぶつぶつ」）。6 章の形式で。
- 大きさは m で書く。ゆかに置くものは**底が平ら**な形にする。

### 雰囲気画
- `mood_<ステージ>.png`：16:9（1920×1080 以上）。ミクロごうの視点でそのステージを見た 1 枚。色・光・遠近の雰囲気を伝える。3D にはしない（Claude が色と光の設定を合わせる参考）。

## 8. spec に書くこと（3D 変換用）

```markdown
# <アセット名>（3D 変換用）

## 納品物
- <ファイル名>：<向き>

## 寸法
- 全長／高さ／幅（m）。ミクロごう（1.4 m）との比。目の直径、口の幅

## 部品の分け方
- 体：球（半径 x m）／ 目：球 ×2 ／ 角：円すい ×2 …（分かる範囲で）

## 色見本
| 部位 | hex | 材質 |

## 動く部分・表情
- 何がどう動くか。表情は目・口のどこが変わるか

## 未納品・発注書と違う点
```
