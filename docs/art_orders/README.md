# Codex への作画発注書（からだのなか だいぼうけん）

絵と 3D モデルのデザインは **Codex（作画担当）** に発注し、納品された絵をもとに **Claude が 3D モデル・UI・ステージに組み込む**。
いまゲームに入っている見た目はすべて**仮**（Blender スクリプトで自動生成した形）で、同じ名前のファイルを置きかえるだけで本番に差しかわるようにしてある（`取り込み手順.md`）。

発注の回し方は『アークウォーカー』（project-relic）で回っている方法と同じ。

---

## 発注の進め方（全体の流れ）

```
第1弾  W0 アートバイブル（画風 3 案）
          ↓ ユーザーが 1 案を選ぶ（修正指示も可）→ Claude が発注書の「選定案」を埋める
第2弾  W1-01 主人公たち / W2-01 てき / W2-02 なかま   ← 3 本を並行して出してよい
          ↓ ユーザーが見た目を確認、Claude が 3D 化できるかを確認（足りなければ修正依頼 r2）
          ↓ Claude が 3D 化して GLB を差しかえ、結果を `W*_<名前>3D化の結果.md` に書く
第3弾  W2-03 アイテムと小物 / W4-01 UI / W4-02 ものしりカードの挿絵
第4弾  W3-01 からだのぶたい（10 ステージの雰囲気・表面・部品）
以降   新しいステージ（骨・筋肉・皮ふ・腎臓・肝臓など）を足すときは、ステージ 1 つにつき W3 の形式で 1 本
```

- **絵を待たずに進める**：ゲームの仕組み・文章・テスト・音は、仮の見た目のまま進める。
- **絵が届いたら差し込む**：届いた順に組み込み、仮のものから置きかえる。

### 1 回の発注で Codex に渡すもの
1. `00_共通ルール.md`（毎回必ず）
2. `01_3D変換用の絵の条件.md`（3D にするものを含む発注のとき）
3. その回の発注書（例：`W1_01_主人公たち.md`）
4. W1 以降は、選ばれたアートバイブル一式（**A-model**：`art/w0` ブランチの `artbible_a_model_*.png` と、`art/concepts/W0_art_bible/spec_a_model.md`・`selection_a.md`）

渡し方は `codex_prompts.md` のプロンプトを Codex に貼るだけ（リポジトリの取得から納品の push まで Codex が行う）。

### 納品先
- リポジトリの `art/concepts/<波>_<アセットID>/` に置く（例：`art/concepts/W1_hero/`）。
- Codex は作業ブランチ `art/<波>`（例：`art/w1-hero`）にコミットして push する。Claude がそのブランチを取り込んで確認・組み込みをする。
- ファイル名の規則は `00_共通ルール.md` を参照。

### 確認と修正
1. **ユーザー**が見た目を確認する（子どもが見て楽しいか、こわすぎないか、既存作品に似ていないか）。
2. **Claude** が「3D 化・組み込みに必要な情報がそろっているか」を確認する（向きの整合、寸法、hex の色、透過、大きさ）。
3. 修正が必要な場合は、番号つきの修正指示を出す（`codex_prompts.md` 3 章）。修正版はファイル名の末尾に `_r2`、`_r3` を付けて納品する（古い版は消さない）。
4. 組み込んだら、結果を `W*_<名前>3D化の結果.md`（3D）または `W*_<名前>取り込みの結果.md`（2D）に書き、`docs/dashboard.md` を更新する。

## ゲームの要約（Codex 向け）

- 対象は **6〜10 歳の子ども**。ちいさくなった「ミクロごう」に乗って、ともだちの **はなちゃん** の体の中に入り、臓器をひとつずつ たすけながら 体のしくみを学ぶ 3D ゲーム。
- 口 → 食道 → 胃 → 小腸 → 血管 → 心臓（右） → 肺 → 心臓（左） → 脳 → 鼻（くしゃみで脱出）の 10 ステージ。
- 敵（ばいきん・ウイルス）は「おくすりバブル」でやっつけ、なかま（赤血球・白血球など）は さわって応援する。
- 雰囲気は **明るくて やさしい絵本の世界**。こわくない。血の中でも「あかるい赤」。敵も「ちょっといたずらな顔」で、残酷さは出さない。
- 詳しくは `docs/design.md`（企画）と `godot/src/autoload/stage_db.gd`（全文章）を参照してよい。
