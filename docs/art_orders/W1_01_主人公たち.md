## 1. 描くもの

### `pod`：ミクロごう（主人公の船）
| 項目 | 内容 |
|------|------|
| 役割 | プレイヤーが操作する船。画面ではつねに **後ろ上から** 見える。だから **後ろ姿でも かわいく、前後が分かる** こと |
| 大きさ | 全長 1.4 m（ゲームの基準）。幅 1.2 m、高さ 1.0 m 前後 |
| 形の案 | 丸い船体。前に透明の **ドーム（まど）**、中にパイロットの顔が見える。左右に小さな **ひれ**、上に小さな **しっぽのひれ**、後ろに **光るプロペラ（輪）**。前の下に小さな **ライト** |
| 色の案 | 船体 白、ひれ 黄色、まど 水色の透明、プロペラ 水色の発光、おなかに ピンクの帯（案なので変えてよい） |
| 動き | プロペラが回る（別部品）。やられると 一瞬 ちぢむ。ダッシュで すこし 前に傾く |
| 避けるもの | 『Among Us』の宇宙服、『ミニオンズ』、潜水艦そのままの形 |

### `pilot`：主人公（パイロット）
| 項目 | 内容 |
|------|------|
| 役割 | プレイヤー自身。名前は決めない。まどから顔と上半身が見えるだけ（全身の 3D は作らない） |
| 年齢・性別 | 6〜10 歳。性別は決めない（どちらにも見える髪型と服） |
| 服の案 | 白衣風の上着＋ゴーグル（頭の上に上げている）。「ちいさな おいしゃさん」 |
| 表情 | 通常・うれしい・びっくり・いたい（4 つ） |

### `pico`：ドクター・ピコ
| 項目 | 内容 |
|------|------|
| 役割 | 案内役のロボット。HUD の ふきだしの横に **顔アイコン** として出る。ものしりカードの絵にも出る。ゲームの 3D の中では ほとんど出ない |
| 大きさ | 直径 0.5 m の球 |
| 形の案 | 水色の 丸い体、アンテナ（先に黄色い玉）、小さな 両手。にこにこ顔。白衣っぽい模様や 聴診器があると「おいしゃさん」らしい |
| 表情 | 通常・うれしい・びっくり・こまった（4 つ） |
| 避けるもの | 『ドラえもん』『ベイマックス』を連想させる色と形 |

### `hana`：はなちゃん
| 項目 | 内容 |
|------|------|
| 役割 | 体の持ち主の ともだち。**ステージ選びの画面で、正面の全身が「からだの地図」として出る**（画面の左 1/3、縦長。臓器の位置に番号ボタンが乗る）。物語のカードにも出る |
| 年齢 | 7 歳くらい。性別はどちらでもよいが、名前は「はなちゃん」 |
| 服の案 | 明るい色のシャツと半ズボン（臓器の位置が分かるよう、体の輪郭が隠れない服） |
| 表情 | 元気がない（かぜ・おなかが痛い）、元気（最後）、びっくり（くしゃみ） |
