## 目的

ゲーム全体の見た目の方向性を決める。**方向性の違う 3 案**を描いてほしい。ユーザーが 1 案を選び、以後のすべての発注はその画風で描く。

この段階では、キャラクターのデザインはまだ確定していない。あくまで「画風の見本」として描いてよい（W1・W2 で本番のデザインを作る）。

---

## 世界と雰囲気

- 6〜10 歳の子どもが遊ぶ、**体のしくみを学ぶ 3D ゲーム**。
- ともだちの「はなちゃん」が かぜを ひいて おなかも いたい。主人公は ちいさな船「ミクロごう」に乗って ちいさくなり、口から入って 体の中を たすけてまわる。
- 口 → 食道 → 胃 → 小腸 → 血管 → 心臓（右） → 肺 → 心臓（左） → 脳 → 鼻。最後は くしゃみで 外へ。
- 敵は ばいきん・ウイルス（「おくすりバブル」で やっつける）。なかまは 赤血球・白血球・ぜんだまきん など（さわって 応援する）。
- 雰囲気は **明るくて やさしい絵本の世界**。こわくない、血なまぐさくない。体の中は「あたたかくて ふしぎな テーマパーク」のように見せる。

### 全案に共通する条件
| 項目 | 条件 |
|------|------|
| 読みやすさ | 3D ゲームの画面で、主人公・てき・なかま・ひろえる物・ゴールが ひと目で分かること。ゆか と 壁が 区別できること |
| 色 | パステル寄り。体の中は赤やピンクが多いので、**赤の中でも主人公や目印が目立つ色の決まり**を提案してほしい（例：主人公は白＋黄、てきは紫系、なかまは緑・白系、目印は黄色の発光） |
| 形 | 丸い塊でできたキャラクター。目が大きい。ローポリ（1 体 2,000〜6,000 三角形）で再現できること |
| 文字 | 画面の文字はゲーム側で描く（丸ゴシック体）。絵には文字を入れない |

### 3 案の振り分け（目安）
3 案は、塗り方と「線」の扱いがはっきり違うものにしてほしい。以下は目安であり、より良い振り分けがあれば提案してよい。

| 案 | 塗り方の方向 | 線 | ねらい |
|----|-------------|----|-------|
| A | 絵本・ガッシュ画のような柔らかい塗り | 線なし | やさしい、あたたかい。小さい子向け |
| B | アニメ塗りのセル調（影 1 段） | 太めの輪郭線 | はっきり、元気。ゲームらしい |
| C | 粘土やフェルトのような手ざわりのある質感（クレイ風） | 線なし | おもちゃらしい立体感。3D と相性がよい |

## 納品物（1 案につき以下の 4 点＋spec_<案>.md）

### 1. キービジュアル（`artbible_<案>_keyvisual.png`）
- 16:9、3840×2160px 推奨（最低 1920×1080px）。
- 内容：ピンクの ふわふわした 体の中（口か血管）を、ミクロごうが 進んでいる。船の まどから 主人公（子ども）の 顔が 見え、船の横に ドクター・ピコ（小さな丸いロボット）が 浮かぶ。遠くに ゴールの 黄色い わっか。手前に 笑顔の 赤血球。
- 「ぼうけんの わくわく」と「からだの なかの ふしぎさ」を伝える。

### 3. ステージの見本（`artbible_<案>_stages.png`）
次の 3 か所を、ミクロごうの視点の小さな絵（各 1280×720 以上）で 1 枚に並べる。
1. くち（口）：舌の上。まわりに 歯。奥に のど の あな。
2. けっかん（血管）：赤い くだの中。赤血球が 流れてくる。
3. のう（脳）：むらさきの ふしぎな広場。神経の 光る線。

### 4. UI の見本（`artbible_<案>_ui.png`）
1920×1080 の画面の見本 1 枚：左上に ハート 3 つ、右上に ミッションの札、下に ドクター・ピコの ふきだし（顔つき）、まん中に ゲーム画面（上の 1 の口でよい）。ボタン（はじめる・わかった！）の見本も 2 つ。
文字は「ダミー」として四角の帯で表してよい（文字はゲーム側で描く）。

### 5. spec_<案>.md
`00_共通ルール.md` の 6 章の項目に加えて、次を書く。
- その案の「色の決まり」：主人公、てき、なかま、ひろえる物、ゴール、ゆか、壁、それぞれの hex と考え方。
- 線の太さ（線がある案）、塗りの段数。
- 3D にしたときに どう見せるか（平らな色、少しの明暗、輪郭線の有無）。
